# Design Handoff: Spec 013 — Multilingual UI and Content (`fi` / `sv` / `en`)

Scope: Design-only handoff for Hydrogen (`docs/specs/013-i18n.md`, building on `docs/design/001-kaamos-sky.md` and `docs/specs/012-ask-milestones.md`).
Files changed by Argon: `docs/design/013-i18n.md` only.

---

## 1. Design Decisions & Rationale

1. **Sky-view top-right language switcher without color dots:** Placing `Suomi | Svenska | English` at top-right (`top: 22px; right: 28px`) outside `#sky-top-bar` avoids crowding the top-left row (wordmark, search input, Ask/Search, lens switcher, demo chips) and preserves `#ask-panel` / `#search-results-panel` vertical clearance (`max-height: calc(100vh - 295px)`). Dots (`--snow`, `--birch`, `--lichen`) are strictly omitted because on stars, search results, and `#panel-languages` they denote **article language**, not UI chrome language.
2. **Boundary-placed `"Machine-translated from <language>"` provenance tag:** Placing the muted `--frost` tag directly between the original-language heading/header and the translated body establishes a clear visual seam between verbatim Wikipedia text above and LLM-translated prose below. It avoids `--lingon` (reserved for edit wars) and `--birch` (Swedish / constellations / ghosts).
3. **Inline optional `changed_by` attribution beside the Ask milestone label:** Inside `.milestone-detail-box`, `changed_by` sits right alongside the translation tag in a compact `.milestone-meta-strip` directly above the translated answer and `facts[]`, distinguishing the *edit that introduced the change* (`changed_by.url`) from the *snapshot sentence citation* (`fact.url`).
4. **Editorial left-rule quote blocks for original-language fact sources:** Existing `.summary-trail-fact-chip` pills cannot comfortably hold 15–30 word verbatim source sentences and `?oldid=` links. Replaced/augmented with stacked `.fact-source-item` rows where the translated claim sits in `--font-ui` `--snow` above a calm `2px solid var(--border)` left-bordered `--font-serif` (`Literata`) `--frost` quote carrying `lang="<sourceLang>"` and an inline trailing `.oldid-anchor`.
5. **Quiet single-line fallback note & link-styled sibling offer:** Cache misses stay calm and non-alarming (`border-left: 2px solid var(--border)`, no box/alert tint), while the sibling offer sits directly under `#panel-languages` as a lightweight underlined action link with the target star-language dot so it never competes with the primary `--snow` `Summarize` button.

### 3.1 Language Switcher (`#lang-switcher`)

- **Placement & mode visibility:**
  - Direct child of `<main class="kaamos-viewport">` (sibling of `#sky-top-bar`, `#sky-legend`, `#timeslider-root`).
  - Sky-view only: whenever `#sky-top-bar` is hidden (Summary Trail and Talvitie modes), hide `#lang-switcher` (`langSwitcher.hidden = true` alongside `skyTopBar.hidden = true` in `src/ui.js`).
  - Desktop (`> 1320px`, `#article-panel` closed): `top: 22px; right: 28px;`.
  - Desktop (`> 1280px`, `#article-panel` open, `450px` wide): shifts left via `.kaamos-viewport:has(#article-panel:not([hidden])) .lang-switcher` to `right: 490px` (`28px + 450px + 12px` clearance; at `1281px` viewport, left edge is `1281 - 490 - 194 = 597px`, clearing `#sky-top-bar`'s `28 + 560 = 588px`).
  - Medium laptop (`1181px–1280px`, `#article-panel` narrows to `400px`): shifts to `right: 444px` (`28px + 400px + 16px`).
  - Narrow desktop with panel open (`901px–1180px`): hide `.lang-switcher` when `#article-panel` is open (`display: none`) so it never collides with `#sky-top-bar`; when the panel closes, it reappears at `top: 22px; right: 28px;`.
  - Mobile / narrow bottom-sheet (`<= 900px`): `#article-panel` docks at `bottom: 0; width: 100%; max-height: 56vh;`, leaving top-right open. `#lang-switcher` sits at `top: 16px; right: 16px;` while `.top-bar-row .search-form` wraps below `.wordmark` (`flex-basis: 100%`), keeping `.wordmark` (left) and `#lang-switcher` (right) on row 1 with `47px+` clearance even at `360px` width.
- **Labels & states:**
  - Fixed endonyms (never translated): `Suomi`, `Svenska`, `English`.
  - States: `default` (`--frost`, transparent), `hover` (`--snow`), `is-active` (`--kaamos` fill, `1px solid var(--snow)`, `--snow` text, `font-weight: 600`), `focus-visible` (inherits global `button:focus-visible` `2px solid var(--snow)` outline).
  - **Dot color rule:** No dots. Star language dots mean article language; using them on UI chrome would falsely imply filtering stars by language.

### 3.2 `"Machine-translated from <language>"` Label (+ Optional `changed_by` on Ask Milestones)

- **When shown:**
  - **Summarize Overview & Section cards** (both `.summary-focused-overlay` and non-far `.summary-css3d-card` `.is-next-1`/`.is-next-2` trail cards): when `mode === "llm"` and `out_lang === ui && out_lang !== article.lang`. Never on `.is-far` cards (`diff >= 3`, title-only) or ghost cards (verbatim Wikipedia text).
  - **Ask top-level answer:** when `out_lang` is set and one or more entries in `sources` have `source.lang !== out_lang`. List each differing source language **once** (preserving source order, deduplicated).
  - **Ask selected milestone (`.milestone-detail-box`):** when `out_lang` is set and `out_lang !== "fi"` (milestone histories are Finnish `wikihistory`). When `out_lang` is `null` or absent -> no label.
- **Exact copy:**
  - Single differing language (`article.lang` or 1 Ask source lang):
    - `fi`: `Konekäännös suomesta` / `Konekäännös ruotsista` / `Konekäännös englannista`
    - `sv`: `Maskinöversatt från finska` / `Maskinöversatt från svenska` / `Maskinöversatt från engelska`
    - `en`: `Machine-translated from Finnish` / `Machine-translated from Swedish` / `Machine-translated from English`
  - Multiple differing Ask source languages (e.g. `fi` + `en` under `sv` UI): join inflected source-language tokens with `, ` after the prefix (`Maskinöversatt från finska, engelska`).
- **Placement:**
  - **Summarize cards:** immediately below `.summary-trail-title` and above `.summary-trail-tldr` / `.summary-trail-oneline` (avoids crowding `.summary-trail-kicker` on 390px/340px cards and marks the exact language boundary beneath the original-language title).
  - **Ask top-level answer:** inside `.ask-panel` immediately above `.ask-answer-body` (below `.overlay-card-header`).
  - **Ask selected milestone:** inside `.milestone-meta-strip` directly below `.milestone-detail-header` (and `.milestone-comment` if shown), above `.milestone-answer-paragraph`.
- **Optional `changed_by` on selected Ask milestone (Spec 012):**
  - When `selectedMs.changed_by` is non-null (`{ rev_id, row_start, user, comment, url }`), display it inside `.milestone-meta-strip` right next to `.mt-label` (wraps cleanly on narrow panels), using `fmtDate(changed_by.row_start)` and natural phrasing rather than `A · B · C` middots:
    - Example (`en`): `Changed by Whiskey~fiwiki, 7 Nov 2006` + `<a href="..." target="_blank" rel="noopener noreferrer" class="oldid-anchor">oldid=1862876</a>`
    - Example (`fi`): `Muutos: Whiskey~fiwiki, 7.11.2006` + `oldid=1862876`
    - Example (`sv`): `Ändrad av Whiskey~fiwiki, 7 nov. 2006` + `oldid=1862876`
  - If `changed_by` is `null` (e.g., first milestone) and `out_lang === "fi"` or `null`, `.milestone-meta-strip` is omitted.

### 3.3 Original Source Sentence Under a Translated Fact (Summarize & Ask Milestones)

- **Shared pattern:** Used identically on:
  - **Summarize Overview & Section cards** (on `.summary-trail-card.is-focused` only — keep CSS3D `.is-next-1`/`.is-next-2` preview cards compact without full fact quotes; non-translated summaries keep `.summary-trail-fact-chip`). Each fact displays `f.label`, `f.value`, `f.source` (`lang="<article.lang>"`), and `https://<article.lang>.wikipedia.org/w/index.php?oldid=<rev_id>`.
  - **Ask Selected Milestone** (`selectedMs.facts[]`): each fact displays `f.text`, `f.source_sentence` (`lang="fi"`), and `f.url` (`?oldid=`).
- **Visual separation:**
  - Stacked `.facts-source-list` (`gap: 10px`), each `.fact-source-item` flat with `padding-top: 8px; border-top: 1px solid var(--border)` (first item `padding-top: 0; border-top: none`) — no nested card boxes inside cards.
  - **Translated claim (`.fact-claim`):** `--font-ui`, `0.8125rem` (`13px`), `line-height: 1.45`, `--snow` (`<strong>` in `600` for Summarize `label:`).
  - **Verbatim original sentence (`.fact-source-quote`):** `blockquote` with `border-left: 2px solid var(--border); padding-left: 9px; margin-top: 4px;`, upright `--font-serif` (`Literata` `400` — avoids faux-italic distortion since `index.html` loads weights `400` and `600` upright only), `0.8125rem` (`13px`), `line-height: 1.5`, color `--frost`.
  - **`lang` attribute placement:** Put `lang="<article.lang>"` (or `lang="fi"`) on `<span class="fact-source-text" lang="fi">` wrapping **only** the verbatim sentence, keeping `.oldid-anchor` outside that span.

## 4. Text Expansion Audit (`~30%` longer Finnish / Swedish strings)

Existing rules in `src/styles.css` that clip, overlap, or squeeze when English strings expand by ~30%:

| Selector (`src/styles.css`) | Current Constraint | Risk in `fi` / `sv` | Required CSS Adjustment |
| :--- | :--- | :--- | :--- |
| `.search-input` / `.search-clear-btn` | `padding: 0 56px 0 12px` | `Tyhjennä` (~68px) overlaps typed query | Increase right padding to `padding: 0 76px 0 12px` |
| `.prompt-chip` | `height: 28px` fixed | Wrapped chips (`Miten talvisota päättyi?` / `Moskovan rauhansopimus…`) clip vertically on narrow viewports | `min-height: 28px; height: auto; padding: 4px 10px; line-height: 1.25; text-align: left;` |

| `.panel-tabs` / `.panel-tab-btn` | No `flex-wrap`, fixed `height: 30px` | `Genom tiderna` / `Ajan myötä` safe on desktop, tight on 360px sheet | Add `flex-wrap: wrap` on `.panel-tabs`; `min-height: 30px; height: auto; padding: 4px 12px;` |

## 5. Responsive & Accessibility Notes (Within Spec 013 Boundaries)

- **Out of scope per Spec 013:** Do **not** add new `aria-label` translations, new keyboard handlers, or ARIA refactoring; keep existing `aria-label` values untranslated.
- **Required semantic attributes per Spec 013:**
  - Set `document.documentElement.lang` (`"fi" | "sv" | "en"`) at startup.
  - Apply `lang="<article.lang>"` on `<span class="fact-source-text">` in Summarize facts and `lang="fi"` on `<span class="fact-source-text">` in Ask milestone facts.
- **Focus & state:** All new `<button>` controls (`#lang-switcher .lang-switch-btn`, `#panel-sibling-offer`) automatically inherit the global `button:focus-visible` (`outline: 2px solid var(--snow); outline-offset: 2px;`) rule in `src/styles.css`.
- **Responsive summary:** No horizontal page overflow at `1440px`, `1280px`, `1024px`, or `390px` (bottom-sheet mode). `#lang-switcher` hides automatically when `#sky-top-bar` is hidden (Summary/Talvitie) or when `#article-panel` is open in the tight `901px–1180px` band.

## 6. Open Questions / Assumptions for Hydrogen

1. **Multi-language Ask `.mt-label` helper:** When Ask `sources` contains multiple languages differing from `out_lang` (e.g. both `fi` and `en` under `sv` UI), combine them into a single label via a prefix + per-language inflected-noun map (`Maskinöversatt från finska, engelska` / `Konekäännös suomesta, englannista` / `Machine-translated from Finnish, English`) so grammar stays natural without emitting multiple badges.
2. **Summarize non-translated vs. translated facts:** Keep existing compact `.summary-trail-fact-chip` pills when `out_lang === article.lang` (no translation), and render `.facts-source-list` / `.fact-source-item` (including `sec.facts` on focused section cards) when `mode === "llm" && out_lang === ui && out_lang !== article.lang`.
3. **Ask milestones `changed_by` optionality:** Displaying `changed_by` in `.milestone-meta-strip` next to `.mt-label` is optional per task instructions; if omitted, `.milestone-meta-strip` still cleanly hosts `.mt-label` alone above `.milestone-answer-paragraph` and `.facts-source-list`.
4. **`:has()` support:** `src/styles.css` already relies on `.kaamos-viewport:has(#article-panel:not([hidden]))` for Summary and Talvitie layouts, so using the same selector for `#lang-switcher` is consistent with existing browser targets (modern Chromium).
